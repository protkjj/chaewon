# 단어장

영어 단어를 추가하고, 낱말카드로 외울 수 있는 앱이야.

---

## 접속 방법

같은 Wi-Fi에 연결된 상태에서 Safari로 접속해:

```
http://172.30.1.21:8082
```

---

## 화면 구성

### 1. 홈 화면

앱을 열면 3개 버튼이 보여:

| 버튼 | 설명 |
|------|------|
| **단어장** | 알파벳별로 단어 보기 |
| **단어추가** | 새 단어 입력 |
| **낱말카드** | 전체 단어 학습 |

---

### 2. 단어장 (알파벳 그리드)

A~Z 알파벳 버튼이 나와. 각 버튼에 그 알파벳의 단어 수가 적혀 있어.

- 알파벳을 누르면 그 글자로 시작하는 단어 목록이 나와
- 오른쪽 위 🔍 버튼을 누르면 **검색** 가능

---

### 3. 단어 목록 (알파벳별)

예를 들어 A를 누르면 A로 시작하는 단어들이 쭉 나와.

- **낱말카드** 버튼: 이 알파벳 단어만 카드로 학습
- **+ 추가** 버튼: 단어 추가 화면으로 이동
- 각 단어 오른쪽 **×** 버튼: 그 단어 삭제 (확인 팝업 뜸)
- 오른쪽 위 🔍: 검색

---

### 4. 단어추가

새 단어를 입력하는 화면이야. **한 줄에 하나씩** 이런 형식으로 써:

```
apple — 사과
book — 책
accommodate — 수용하다, 숙박시키다, 부응하다
```

#### 입력 형식

아래 형식 다 인식돼 (편한 대로 써도 됨):

| 형식 | 예시 |
|------|------|
| em dash | `apple — 사과` |
| 하이픈 (공백 있음) | `apple - 사과` |
| 하이픈 (공백 없음) | `apple-사과` |
| 공백만 | `apple 사과` |

#### 여러 뜻 입력

뜻이 여러 개면 **콤마(,)** 로 구분:

```
accommodate — 수용하다, 숙박시키다, 부응하다
```

#### 중복 처리

이미 있는 단어를 다시 추가하면:

- 새로 만들지 않고 **기존 단어에 병합**됨
- 뜻이 새로 추가된 게 있으면 합쳐짐
  - 기존: `가, 나` + 새로 입력: `가, 나, 다` → `가, 나, 다`
- 기존 뜻이 더 많으면 줄어들지 않음
  - 기존: `가, 나` + 새로 입력: `가` → `가, 나` 그대로
- 영어 단어 옆에 주황색으로 **×2**, **×3** 같이 추가된 횟수가 표시됨

입력 중에 아래쪽에 **"15개 인식"** 같이 실시간으로 몇 개가 파싱되는지 보여줘.

---

### 5. 검색

🔍 버튼을 누르면 검색 화면이 나와.

- **영어**로 검색: `isomorphism` 입력하면 해당 단어 찾기
- **한국어**로 검색: `동형사상` 입력하면 뜻에 포함된 단어 찾기
- 타이핑하는 즉시 결과가 나옴
- 매칭된 부분은 **노란색**으로 하이라이트

---

### 6. 낱말카드 (학습 모드)

퀴즈렛처럼 카드를 넘기면서 단어를 외울 수 있어.

| 동작 | 방법 |
|------|------|
| 카드 뒤집기 | 카드 **탭** |
| 다음 카드 | **왼쪽으로 스와이프** 또는 ▶ 버튼 |
| 이전 카드 | **오른쪽으로 스와이프** 또는 ◀ 버튼 |
| 셔플 (순서 섞기) | 가운데 🔀 버튼 |
| 나가기 | 왼쪽 위 × 버튼 |

카드 앞면에는 영어 단어, 뒷면에는 한국어 뜻이 나와.
뜻이 여러 개면 번호 매겨서 보여줘:

```
1. 수용하다
2. 숙박시키다
3. 부응하다
```

키보드가 연결되어 있으면:
- **스페이스/엔터**: 뒤집기
- **← →**: 이전/다음

## 데이터 저장

- 모든 데이터는 **기기 안에** 저장돼 (인터넷 필요 없음)
- 앱을 껐다 켜도 단어가 그대로 남아 있어
- 단, Safari에서 **방문 기록 삭제**하면 데이터도 날아가니 주의!
